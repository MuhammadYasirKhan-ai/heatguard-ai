🚀 Project Overview

HeatGuard AI is an urban heat risk intelligence platform built for FortyGuard Hackathon'26.


Uses FortyGuard's NVIDIA-recognized Temperature API (2m precision, 20m² resolution) with Claude AI to deliver actionable heat risk intelligence for cities, governments, and communities.


Architecture: Direct API calls with secure key management.
FortyGuard key stored in FORTYGUARD_API_KEY constant · Claude key in CLAUDE_API_KEY constant.


API Used: FortyGuard Temperature API
Endpoint: POST /v1/heat-intelligence
Data: Real-time · 2m above ground · 20m² resolution · LTM-powered


Challenge Tracks: Dashboards · Predictive Models · AI Agents

Use Cases: Resilient Cities · Government & Environment
